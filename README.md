# Aurory

Aurory is a premium bikini model-discovery website built with React and Vite.

This MVP is a public visual homepage only. Visitors can browse sample model
profiles and contact a clearly marked sample vendor through external WhatsApp
or Telegram links.

## Scope

- Public homepage
- Featured bikini model cards
- Search and client-side filtering
- Browse by city
- Browse by category
- External representative contact links

No backend, database, authentication, dashboards, forms, bookings, payments, or
internal messaging are included in this first version.

## Scripts

```sh
npm.cmd run dev
npm.cmd run build
npm.cmd run lint
```
